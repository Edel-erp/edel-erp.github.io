# Edel website

The website for Edel Trading PLC: electronic invoicing and ERP software for Ethiopian businesses, Edel Academy training, and a waitlist.

- `index.html`: the whole site (styles and scripts included)
- `edel-logo-web.png`: the logo

Hosted with GitHub Pages. Settings for the chat assistant (`AI_ENDPOINT`, `TAWK`), social links (`SOCIAL`) and waitlist delivery (`WAITLIST_ENDPOINT`) are near the top of the script in `index.html`.
